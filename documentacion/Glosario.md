# Glosario

- GitHub: Plataforma para alojar y gestionar repositorios.
- Repositorio: Espacio donde se almacena el código y los archivos.
- Markdown: Lenguaje utilizado para dar formato a documentos.
- Commit: Registro de cambios realizados en un repositorio.
- Roadmap: Planificación de las etapas de un proyecto.
